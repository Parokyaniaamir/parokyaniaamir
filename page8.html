1. HTML Sectioning

HTML sectioning divides a webpage into different parts. Examples are header, nav, main, section, article, and footer.

2. 3 Types of CSS

Inline CSS: CSS written inside an HTML element.

Internal CSS: CSS written inside the style tag.

External CSS: CSS written in a separate CSS file.

3. CSS Selectors

Element Selector: Selects HTML elements such as p and h1.

Class Selector: Selects elements using a class name.

ID Selector: Selects an element using an ID.

4. CSS Border

CSS borders are used to create lines around HTML elements. Borders can have different colors, widths, and styles.

5. CSS Background

CSS backgrounds can be used to add colors or images to the background of a webpage.

6. CSS Box Model

The CSS Box Model has four parts: content, padding, border, and margin.
